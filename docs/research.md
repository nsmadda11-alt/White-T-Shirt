# T-Shirt Research Record: Null Variable

## 1. Clothing Site Competitor Analysis
* **Site 1 (Everlane - Nov 2026):** Minimalist layout with heavy emphasis on sustainable materials. *Observation:* Clean grid layout with neutral backdrops. *Suggestion:* A distraction-free visual presentation builds trust for premium basics.
* **Site 2 (Gymshark - Nov 2026):** High-contrast imagery with athletic fit focus. *Observation:* Bold typography highlighting technical product features. *Suggestion:* Technical specs should be upfront rather than hidden in dropdowns.
* **Site 3 ( Uniqlo - Nov 2026):** Functional catalog style emphasizing durability and everyday utility. *Observation:* Focus on fabric weight and structural longevity. *Suggestion:* Emphasize fabric quality and clean syntax branding.

## 2. Positioning & Persona Hypotheses
* **Positioning Option A:** High-end boutique streetwear.
* **Positioning Option B (Chosen):** Developer/minimalist essential wear focused on zero distractions.
* **Persona 1 (Primary):** **The Focused Developer** — Seeks clean, durable, non-distracting everyday clothing built for long coding sessions.
* **Persona 2 (Secondary):** **The Tech Minimalist** — Values simple aesthetics, high structural quality, and zero unnecessary logos.

## 3. Brand Identity & Strategy
* **Target Audience:** CS/IT students and software developers who value clean aesthetics and minimal noise.
* **Visual Look:** Dark mode/high-contrast, clean typography, zero bloated design elements.
* **Brand Character:** Direct, precise, technical, functional.
* **Honest Persuasion:** No hype marketing—just clean syntax, high-grade construction, and functional utility.

## 4. Key Assumptions
* Target users prefer minimal branding over large graphic prints.
* Storefront shoppers prioritize clear product specs (fabric weight, sizing) over decorative imagery.
